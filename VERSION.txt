MIN WORKS UI v25

- 과거 리비전 CSS·JS를 최신 통합본 2개로 병합
- GitHub Pages 배포 파일과 서비스워커 캐시를 v25 최신본으로 정리
- 선택한 민트색 입체 M 아이콘으로 PWA·아이폰·안드로이드 아이콘 교체
- 기존 지출·기성 결재 칸반 제거 및 예정 지출서 목록으로 재구성
- 공정별 공사금액·지출 예정금액 입력 시 금회 기성률 자동 계산
- 월기성·긴급지출 색상 구분, 담당자·공무부·관리부·대표·이사 확인 기록
- 현장 자금 요약을 예정 지출과 이번 달 수금 예정 데이터로 자동 합산
- 거래처 수금 예정에 공사기간·계약금액·입금금액·기성률·잔금 자동 계산 적용
- 모바일 상단 현재 현장 영역 제거
- 모바일 홈 바로가기 및 전체 메뉴 추가
- 일정 관리 전용 탭 숨김
- 홈 하단 개인 Google 캘린더 연결 안내 및 바로가기
- 공사일보 개별 PDF 저장
- 현장별 공사일보 통합 PDF 저장
- 사진 포함/제외 선택 및 예상 페이지·사진 수 표시
- MIN WORKS 전용 앱 아이콘(안드로이드·아이폰) 적용
- 휴대폰 홈 화면 설치 버튼과 기종별 설치 안내 추가
- 설치 후 전체 화면 앱처럼 실행되는 PWA 구성
- 흰색 반사광과 불필요한 3D 효과를 제거한 평면형 M·새싹 아이콘 v2
- 모바일 하단에 이슈 탭 추가
- 모바일 하단 설정 탭을 전체메뉴로 교체
- 원본 MIN 글자와 점·잎 3개를 살린 프리미엄 3D 앱 아이콘 적용
- 홈 요약 수치를 등록된 현장·일보·이슈에서 실시간 계산
- 확인 대기 일보 카드와 중복 현장 개설·내보내기 버튼 제거
- 공사일보 현장 필터를 등록 현장 기준으로 자동 생성
- 현장 주소 표시 제거 및 공사일보 상태·다운로드 정렬 통일
- Google 가짜 연결 상태 제거, 실제 OAuth 연결 코드와 미설정 상태 분리
- 실명 로그인 환영 문구와 실제 인증 화면 연결
- 사용법 탭을 화면 이동 없는 설명·FAQ 중심으로 전면 개편
- 공사일보 날짜를 실제 선택일 기준으로 분류하고 오늘 보고 수치에서 과거 일보 제외
- 서버 응답 제한시간을 추가해 인증 화면이 무한 대기하지 않도록 보완
- PC 전용 일정 탭 제거, 개인 Google 일정은 홈에서만 표시

중요
- PDF는 브라우저 인쇄 화면에서 "PDF로 저장"을 선택하는 방식입니다.
- Google 캘린더는 실제 읽기 전용 OAuth와 일정 조회 코드가 연결되어 있습니다.
  config.js에 Google OAuth 웹 클라이언트 ID를 입력해야 연결 버튼이 활성화됩니다.
- 현재 이 정적 UI만으로는 여러 직원의 데이터와 사진이 자동 공유되지 않습니다.
  실제 공유에는 서버 API, 공용 데이터베이스, 사진 저장소 연결이 필요합니다.
